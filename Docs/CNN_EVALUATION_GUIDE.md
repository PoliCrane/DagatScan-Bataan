# CNN vs Plain NDWI Threshold — Honest Evaluation Guide

## Why this is needed

The CNN in `services/imageCNNDetection.js` is trained on pseudo-labels generated by the
classical NDWI threshold on the same image it then predicts. This means the CNN cannot be
claimed to be "accurate" by itself — any such claim is circular, because it is only measured
against its own teacher. A thesis panel will reject that argument.

The only defensible way to keep (or drop) the CNN is to compare **both** the CNN output and
the plain threshold against **independent, manually labeled ground truth**, and report which
one wins.

## Procedure

1. Pick 20–30 satellite images (NDWI GeoTIFFs from `uploads/ndwi-generated/` or true-color
   exports) covering different municipalities, years, and coast types (open coast, bays,
   river mouths).
2. For each image, create a labeled mask in any image editor:
   - Same extent as the image (any resolution — the script resizes it).
   - Paint **water WHITE (255)** and **land BLACK (0)**. Use the true-color image of the
     same bounds/year as visual reference when labeling an NDWI file.
   - Save as PNG next to the image, e.g. `bagac_2022_label.png`.
3. Run the evaluation for each pair:

   ```
   node scripts/evaluateCnnVsThreshold.js uploads/ndwi-generated/NDWI_Bagac_2022.tif labels/bagac_2022_label.png
   ```

4. Record IoU, pixel accuracy, precision, and recall for BOTH methods per image
   (a spreadsheet is fine), then average across all images.

## Decision rule

- If the CNN's mean IoU beats the plain threshold by a clear margin (≥2–3 points), keep the
  CNN and report the numbers in the thesis as its measured accuracy.
- If they are equivalent or the threshold wins, switch the pipeline to the plain NDWI
  threshold and state in the thesis that the CNN was evaluated and did not add measurable
  value — this is a legitimate, defensible finding.
- Either way, the thesis reports a real, ground-truth-based accuracy figure for the
  shoreline extraction step instead of a circular one.

## Related tools

- `node scripts/verifyNdwiPolarity.js <ndwi.tif>` — confirms water/land polarity of the
  NDWI export empirically.
- `node scripts/runHindcastValidation.js` — measures end-to-end prediction accuracy
  (a separate question from extraction accuracy).
